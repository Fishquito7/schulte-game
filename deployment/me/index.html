01 / ABOUT

我在折腾什么

写代码和折腾环境对我来说是一件事：发现顺手与别扭之间的缝隙，然后用最小的依赖把它填平。 不追求全家桶和大框架，更喜欢结构简单、哪里出问题一眼能看穿的实用作品——比如把四个经典认知实验拆成四页纯静态前端 + 分模块 Node 服务，跑在自家 NAS 后面。

Agent / DSH 工具链

给 DeepSeek Harness 补齐工程顺手度：Skill 与 MCP 可视化面板、Windows 原生 Git Bash、归档会话管理与快捷指令集。

科研与文档自动化

零依赖 Web & 自托管
